Simple Bevel

Plugin SketchUp untuk membulatkan (bevel) atau memotong miring (chamfer) edge — versi 1.3.3

1. Instalasi

  1. Buka SketchUp, lalu menu Extensions › Extension Manager.
  2. Klik Install Extension… dan pilih file ad_simple_bevel-1.3.3.rbz.
  3. Bila muncul peringatan “unsigned extension”, pilih Yes / Izinkan (plugin ini belum ditandatangani digital).
  4. Toolbar Simple Bevel akan muncul. Jika tidak terlihat: View › Toolbars › Simple Bevel.

File .rbz yang sama dipakai untuk Windows dan Mac — tidak ada versi terpisah. Ikon otomatis menyesuaikan sistem operasi.

2. Tombol & menu

Pilih Rantai EdgeKlik satu edge untuk memilih rantai edge yang menyambung.
Bevel / Chamfer Edge…Proses edge yang sedang terpilih.
Setting…Atur jumlah step (kehalusan) bevel. Default 6.

Semua perintah juga ada di Extensions › Simple Bevel dan di klik kanan › Simple Bevel (muncul saat ada edge terpilih).

3. Cara cepat

  1. Masuk ke dalam group/komponen (double-click) yang edge-nya mau di-bevel.
  2. Pilih edge — dengan Select biasa, atau tombol Pilih Rantai Edge.
  3. Klik Bevel / Chamfer Edge… (atau tekan Enter saat alat Pilih Rantai aktif).
  4. Isi nilai lalu OK:
    • Angka positif, mis. 10mm → bevel bulat dengan radius 10 mm.
    • Angka negatif, mis. -10mm → chamfer (potongan miring) 10 mm di kedua sisi.

Satu kali proses = satu langkah Undo (⌘Z / Ctrl+Z). Nilai terakhir diingat untuk pemakaian berikutnya.

5. Sudut dalam

Pada sudut dalam (cekung), bevel menambah material: angka positif mengisi sudut dengan lengkungan (fillet), angka negatif dengan bidang miring.

6. Setting

Setting… mengatur jumlah step lengkungan bevel (1–64, default 6). Makin besar makin halus tetapi geometri makin berat. Chamfer selalu 1 step.

7. Jika edge dilewati

Setelah proses, plugin menampilkan berapa edge yang dilewati beserta alasannya. Model tidak berubah untuk edge yang dilewati.

PesanSolusi
radius terlalu besarPerkecil nilai; radius harus lebih kecil dari sisi di sebelahnya.
edge harus diapit tepat 2 facePilih edge yang benar-benar berada di antara dua face (bukan garis lepas).
ujung edge harus bertemu tepat 3 edgeUjung edge berada di pertemuan yang rumit — bersihkan garis bantu di sekitar ujung.
rantai bercabangLebih dari 2 edge terpilih bertemu di satu titik — pilih ulang tanpa cabang.
rantai berisi sudut dalamSudut dalam belum bisa dalam rantai; proses edge sudut dalam satu per satu.
orientasi face tidak konsistenKlik kanan face › Orient Faces, lalu ulangi.
Tips: bekerjalah di dalam group/komponen agar bevel tidak menempel ke geometri lain, dan pastikan objek berupa solid (tertutup) untuk hasil terbaik.

8. Uninstall

Extensions › Extension Manager › cari Simple Bevel › Uninstall, lalu restart SketchUp.
